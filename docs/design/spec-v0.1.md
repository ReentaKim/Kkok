## 1. 편집 창
| 영역 | 내용 |
|---|---|
| 제목 막대(52pt, 통합형) | 왼쪽: 캡처 버튼 묶음 영역·창·전체·타이머(FR-01·04·05·06) / 가운데: 문서 이름(캡처 시각 `yyyy-MM-dd HH.mm.ss`) / 오른쪽: 복사(FR-31), 저장…(FR-32) |
| 왼쪽 도구 막대(56pt) | 선택 V, 화살표 A, 글자 T, 도형 R(묶음), 펜 P, 형광펜 H, 모자이크 B, 스탬프 S(묶음), 자르기 C / 구분선 / 현재 색 원(누르면 팔레트) / 굵기 3단 점 |
| 캔버스 | 배경 `#3A3A3C`(다크 모드도 동일). 이미지 가운데, 그림자. 확대·축소 ⌘+ ⌘− ⌘0, 창보다 크면 스크롤 |
| 가장자리 띠 | 이미지 네 변 바깥 22pt. 마우스를 올리면 분홍 반투명 + "＋", 누르면 그쪽으로 이미지 짧은 변의 25%(최소 40px)만큼 흰 여백 추가(FR-18) |
| 아래 막대(56pt) | 분홍 끌기 탭: 썸네일 + "끌어서 붙이기" + "PNG · 가로×세로"(FR-30). 옆에 자동 저장 상태. 오른쪽 확대 비율 |

도구 버튼: 40×40, 모서리 9, 켜진 도구는 현재 색 바탕 + 흰 아이콘(흰색 선택 시 회색 바탕). 묶음 버튼은 오른쪽 아래 작은 삼각형, 누르면 옆으로 팝오버.

## 2. 색과 굵기 (FR-20)
색 12개(4×3 격자 팝오버): 분홍 `#FC0C59`(기본), 빨강 `#FF3B30`, 주황 `#FF9500`, 노랑 `#FFD60A`, 연두 `#8BD83A`, 초록 `#34C759`, 하늘 `#32ADE6`, 파랑 `#0A84FF`, 보라 `#AF52DE`, 갈색 `#A2845E`, 검정 `#1C1C1E`, 흰색 `#FFFFFF` + 사용자 지정(시스템 색 패널).

글꼴(FR-23): 도구 막대 맨 아래 "가" 버튼(현재 글꼴로 표시) → 메뉴에 각 글꼴 이름을 그 글꼴로 보여 줌. 크기 보정 배수: 나눔손글씨 펜 1.35, 도현·주아 1.05, 나머지 1.

| 굵기 단계 | 선 두께(px, 이미지 기준) | 화살표 굵기 | 글자 크기 |
|---|---|---|---|
| 1 작게 | 3 | 6 | 18 |
| 2 보통(기본) | 5 | 10 | 24 |
| 3 크게 | 9 | 16 | 36 |

이미지 기준 px이므로 Retina 캡처(2배)에서는 굵기 단계 값 × 이미지 배율을 쓴다.

## 3. 주석 모양
- **흰 외곽선**: 화살표·글자·도형·선·펜은 같은 모양을 흰색으로 (두께 + 4px×배율) 먼저 그리고 그 위에 색을 그린다. 흰색 주석의 외곽선은 검정 40%.
- **화살표**(FR-10): 꼬리에서 머리로 갈수록 굵어지는 몸통 + 삼각 머리(머리 길이 = 굵기×3.2, 폭 = 굵기×2.6). 꼬리 두께는 굵기의 45%.
- **글자**(FR-11): AppleSDGothicNeo-Bold, 흰 외곽선(글자 크기의 18%). 배경 없음.
- **둥근 사각형**: 모서리 반경 = 굵기×2.
- **형광펜**(FR-14): 노랑 기본(현재 색이 분홍이면 `#FFF700`), 불투명도 55% 곱하기(multiply) 합성, 끝 모양 사각, 두께 = 굵기 단계×12px×배율. 한 획은 한 경로로 그려 겹침이 진해지지 않게.
- **모자이크**(FR-15): 칸 크기 = max(8px, 영역 짧은 변/12)×배율. 테두리 없음.
- **스탬프**(FR-16): 원 지름 = 굵기 단계×14+20(pt×배율), 흰 테두리 3. ✓초록, ✕빨강, ?파랑, !주황, ★노랑, 숫자는 현재 색. 숫자는 1부터 자동 증가.

## 4. 선택 상태 (FR-19)
파란 `#0A84FF` 점선 테두리 + 흰 사각 손잡이 8×8. 화살표·선은 양 끝 원형 손잡이.

## 4-1. 글자 회전·손잡이 커서 (FR-24·25)
- 고른 글자: 회전한 점선 상자, 위쪽 가운데에서 22pt 위에 회전 손잡이(흰 원 16pt + 파란 ↻, 상자와 선으로 연결), 오른쪽 아래 모서리에 크기 손잡이(흰 원 10pt).
- 커서: 손잡이 위에서 ↔(흰 외곽선 검정 양쪽 화살표, 15° 단위로 방향 맞춤), 회전 손잡이는 ↻. 그 밖은 도구별 커서.
- 글자를 고쳐 쓰는 동안은 입력 상자가 수평으로 보이고, 마치면 다시 돈 상태로 그려진다(v0.1 한계).

## 5. 영역 캡처 화면 (FR-01·02·06)
- 끌기 전: 얼린 화면 그대로 + 십자선만(덮개·좌표 없음). 끌기 시작하면 고른 영역 밖만 검정 35% 덮개.
- 십자선: 화면 끝까지 1px 흰 선(검정 그림자).
- 크기 표시: 커서 오른쪽 아래 검정 둥근 상자에 `가로 × 세로`.
- 타이머: 화면 가운데 큰 숫자 원(지름 120) 카운트다운, 덮개는 사라지고 고른 영역 테두리만 남는다.

## 6. 메뉴 막대 아이콘
템플릿 이미지(흑백): 둥근 점 하나에 짧은 화살표가 콕 찌르는 모양. 메뉴: 영역 캡처 / 직전 영역 / 창 / 전체 화면 / 타이머 / — / 클립보드에서 새로 만들기 / 파일 열기… / 최근 항목 ▸ / — / 설정… / Kkok 종료.

## 7. 앱 아이콘
분홍 `#FC0C59` 둥근 사각 바탕 + 흰 굵은 화살표가 오른쪽 아래에서 왼쪽 위의 작은 노란 점을 짚는 모양. 스크립트로 직접 그린다(scripts/generate-icons.sh).
