# Kkok v0.1 PRD

- 작성: 2026-11-13 · 역할: PM
- 근거: [Skitch 분석](../rea/skitch-analysis.md), [결정 기록](../decisions.md)

## 1. 문제와 목표
Skitch는 곧 실행되지 않는다(x86_64 전용). Skitch로 하던 일을 끊김 없이 이어서 하는 것이 목표다.

**핵심 흐름**: 단축키 → 화면 일부 캡처 → 화살표·글자로 짚기 → 하단 탭을 끌어 메신저·문서에 PNG로 놓기. 이 흐름이 **10초 안에** 끝나야 한다.

**하지 않는 것**: 계정, 동기화, 공유 URL, 이메일 보내기, 업데이트 알림, 카메라, PDF 주석(v0.2 후보).

## 2. 사용 환경
macOS 14 이상, Apple 실리콘. 화면 기록 권한 필요. 여러 모니터·Retina 배율 지원.

## 3. 기능 요구사항

### 캡처
| ID | 요구사항 | 수용 기준 | 검증 |
|---|---|---|---|
| FR-01 | 영역 캡처 (기본 ⇧⌘5) | 단축키를 누르면 모든 화면이 얼고 십자선이 뜬다. 끌어서 고르는 동안 가로×세로(pt)가 보인다. 놓으면 편집 창이 열린다. Esc는 취소 | 수동 |
| FR-02 | 영역 다듬기 | 끌고 놓으면 바로 찍힌다(기본, Skitch와 같음). ⌥를 누른 채 놓으면 다듬기 단계: 손잡이로 크기·위치 조절, Enter 또는 "캡처"·"N초 후" 버튼으로 확정 | 수동 |
| FR-03 | 직전 영역 다시 찍기 (⌥⇧⌘5) | 직전 영역 좌표로 바로 캡처한다. 직전 영역이 없으면 FR-01과 같다 | 수동 |
| FR-04 | 창 캡처 (⇧⌘7) | 마우스 아래 창이 강조되고, 누르면 그 창만 그림자 없이 찍힌다 | 수동 |
| FR-05 | 전체 화면 캡처 (⇧⌘6) | 마우스가 있는 화면 전체를 찍는다 | 수동 |
| FR-06 | 타이머 캡처 (⌃⇧⌘5) | 영역을 고른 뒤 카운트다운(기본 3초, 설정 1~15초)이 화면에 보이고 끝나면 그 영역을 찍는다. 메뉴·툴팁을 찍을 수 있어야 한다 | 수동 |
| FR-07 | 다른 경로로 열기 | 이미지 파일 열기(⌘O), 편집 창에 파일 끌어 놓기, Dock 아이콘에 놓기, 클립보드 이미지로 새로 만들기(⌘⇧V), 빈 캔버스(⌘N) | 수동 |
| FR-08 | 픽셀 정확도 | 결과 이미지는 화면의 실제 픽셀 해상도(Retina 2배)다. 여러 모니터에서 고른 영역과 결과가 어긋나지 않는다 | 수동 + 테스트 |

### 주석

| FR-12 | 도형 | 사각형, 둥근 사각형, 타원, 선. ⇧로 정사각·정원·45° 고정 | 수동 |
| FR-13 | 펜 | 자유 곡선, 부드럽게 보정 | 수동 |
| FR-14 | 형광펜 | 반투명 굵은 선. 겹쳐 그려도 같은 획 안에서는 진해지지 않는다 | 수동 |
| FR-15 | 모자이크 | 끈 영역의 원본을 픽셀화한다. 위치·크기 조절 가능. 내보낸 PNG에서 원본 글자를 읽을 수 없어야 한다 | 테스트 |
| FR-16 | 스탬프 | 승인 ✓, 거절 ✕, 물음표, 주의 !, 완벽 ★, 숫자(1·2·3… 자동 증가). 클릭하면 놓이고 크기 조절 가능 | 수동 |
| FR-17 | 자르기 | 자르기 모드에서 영역을 고르고 Enter. 실행 취소 가능 | 수동 + 테스트 |
| FR-18 | 캔버스 넓히기 | 캔버스 가장자리 바깥 띠를 클릭하면 그쪽으로 여백이 늘어난다(흰색) | 수동 |
| FR-19 | 선택·편집 | 선택 도구(또는 주석 클릭)로 고르기, 끌어 옮기기, 손잡이로 크기, Delete로 지우기, 선택한 주석의 색·굵기 바꾸기, ⌘A | 수동 |
| FR-20 | 색과 굵기 | 색 12개(사인펜 세트처럼, 기본 분홍 #FC0C59) + 사용자 지정, 굵기 3단. 마지막 도구·색·굵기를 앱을 다시 켜도 기억 | 수동 |
| FR-23 | 글꼴 | 글자 주석에 글꼴 5가지(기본 산돌고딕 Neo, 프리텐다드, 배민 도현체, 배민 주아체, 나눔손글씨 펜). 도구 막대 "가" 버튼에서 고름. 쓰는 중이거나 선택한 글자에도 바로 적용. 마지막 글꼴 기억. 예전 보관 파일도 그대로 열림 | 테스트 + 수동 |
| FR-21 | 실행 취소 | 모든 편집을 ⌘Z/⇧⌘Z로 되돌림 | 수동 |
| FR-22 | 단축키 도구 전환 | A 화살표, T 글자, R 사각, O 타원, L 선, P 펜, H 형광펜, B 모자이크, S 스탬프, C 자르기, V 선택 (글자 입력 중 제외) | 수동 |

## 4. 비기능
- 단축키 → 십자선까지 0.3초 이내.
- 인터넷 연결을 쓰지 않는다.
- 3000×2000 이미지에서 주석 50개까지 끌기가 끊기지 않는다.
