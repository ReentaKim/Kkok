# Kkok v0.1 테스트 계획

- 작성: 2026-11-13 · 역할: QA(독립)
- 기준: [PRD v0.1](../pm/PRD-v0.1.md), [디자인 명세](../design/spec-v0.1.md), [아키텍처](../dev/architecture.md)
- 결과: [테스트 보고서](test-report-v0.1.md)

## 1. 검증 방법

| 표시 | 뜻 |
|---|---|
| 자동 | `swift test`(저장소 테스트) 또는 QA가 따로 만든 임시 테스트(저장소에 넣지 않음) |
| 코드 | 소스 코드 경로를 읽고 논리를 확인 |
| 화면 | 화면에 띄우지 않는 점검 모드(`KKOK_SNAPSHOT_IN/OUT`)로 편집 창을 PNG로 그려 확인 |
| 수동 | 사용자가 직접 해 보는 확인. 아래 4장의 절차를 따른다 |

QA는 사용자가 이 Mac을 쓰는 중이라 GUI 조작·앱 실행·화면 캡처를 하지 않았다. 캡처·전역 단축키·끌어 놓기·IME처럼 실제 화면과 다른 앱이 있어야 하는 항목은 수동 확인으로 남긴다.

## 2. 준비

1. `swift test` 통과 확인
2. `scripts/build-app.sh --install`로 설치하고 실행(메뉴 막대에 Kkok 아이콘)
3. 화면 기록 권한 허용(처음 캡처 때 안내)
4. 가능하면 모니터 두 대(하나는 Retina, 하나는 일반 배율)를 연결해 둔다
5. 입력 소스 두 개(ABC, 한국어 2벌식)를 켜 둔다

## 4. 수동 확인 절차

각 절차 끝의 "기대"와 다르면 보고서의 해당 FR에 결과를 적는다.

### 캡처

- **M-01 영역 캡처**
  1. 다른 앱(예: Safari)을 앞에 두고 ⇧⌘5를 누른다.
  2. 기대: 0.3초 안에 모든 화면이 멈춘 그림 + 어두운 덮개 + 화면 끝까지 닿는 흰 십자선. 커서 옆에 좌표가 보인다.
  3. 끌면 `가로 × 세로` 숫자가 보이고, 놓으면 바로 편집 창이 열린다.
  4. 다시 ⇧⌘5 → Esc. 기대: 덮개가 즉시 사라지고 편집 창이 열리지 않는다. **Safari를 클릭해 확실히 앞에 둔 직후에도 Esc가 먹는지** 확인한다(앱 활성화 실패 여부).
  5. 커서가 십자 모양인지 확인한다.
- **M-02 영역 다듬기**
  1. ⇧⌘5로 끌다가 ⌥를 누른 채 놓는다.
  2. 기대: 손잡이 4개와 "N초 후", "캡처 ↩" 버튼. 모서리 손잡이로 크기, 안쪽 끌기로 위치가 바뀐다.
  3. Enter → 캡처됨. 다시 해서 "캡처" 버튼, "N초 후" 버튼도 각각 확인.
  4. 다듬기 중 영역 바깥을 끌면 새로 고르기가 시작되는지 확인.
- **M-03 직전 영역**: M-01로 한 번 찍은 뒤 화면 내용을 바꾸고 ⌥⇧⌘5. 기대: 같은 위치·크기가 바로(선택 화면 없이) 찍힌다. 앱을 다시 켠 뒤에도 같은지 확인. 처음 설치 직후(직전 영역 없음)에는 영역 선택 화면이 뜬다.
- **M-04 창 캡처**: ⇧⌘7 → 마우스를 여러 창 위로 옮긴다. 기대: 마우스 아래 창이 파랗게 강조되고 앱 이름·크기가 보인다. 클릭 → 그 창만, 그림자 없이(투명 테두리 없이) 찍힌다. 다른 창에 가려진 창도 그 창만 온전히 찍히는지 확인. Esc 취소 확인.
- **M-05 전체 화면**: 모니터 두 대에서 마우스를 두 번째 화면에 두고 ⇧⌘6. 기대: 두 번째 화면 전체가 실제 픽셀 크기로 찍힌다(아래 막대의 `PNG · 가로 × 세로` 확인).
- **M-06 타이머**: ⌃⇧⌘5로 영역을 고른다. 기대: 화면 가운데 큰 숫자(기본 5)가 1초마다 줄고, 고른 영역 분홍 테두리만 남는다. 카운트다운 중 다른 앱의 메뉴를 열어 둔다. 기대: 결과에 열린 메뉴가 찍히고, 숫자 원·테두리는 찍히지 않는다. 설정에서 타이머를 2초로 바꿔 다시 확인.
- **M-07 다른 경로로 열기**
  1. 편집 창을 연 상태에서 ⌘O로 PNG를 연다.
  2. Finder의 이미지를 편집 창 캔버스(회색 영역 포함)에 끌어 놓는다.
  3. 편집 창이 열려 Dock에 아이콘이 보일 때 그 아이콘에 이미지를 놓는다. (편집 창이 없으면 Dock 아이콘이 없다는 점도 확인)
  4. 다른 앱에서 이미지를 복사(⌘C) 후 Kkok 편집 창에서 ⌘⇧V. Finder에서 파일을 복사한 뒤 ⌘⇧V도 확인.
  5. ⌘N → 흰 빈 캔버스.
- **M-08 픽셀 정확도**
  1. Retina 화면에서 픽셀 경계가 분명한 대상(예: 1px 선이 있는 표)을 영역 캡처 → 저장된 PNG를 미리보기로 열어 크기가 고른 pt × 2인지, 가장자리가 1px도 밀리지 않았는지 본다.
  2. 일반 배율 외부 모니터에서도 같은 확인(배율 1).
  3. 외부 모니터를 주 모니터의 왼쪽·위쪽에 배치(음수 좌표)한 상태에서 영역·창 캡처가 어긋나지 않는지 본다.
  4. 디스플레이 설정에서 "더 넓은 공간" 배율로 바꾼 뒤 1을 반복.

### 주석

- **M-10 화살표**: A → 여러 방향으로 끈다. 기대: 꼬리 가늘고 머리 굵음, 흰 외곽선. 검은 배경·흰 배경 모두에서 보인다. 선택 후 양 끝 원형 손잡이로 고칠 수 있고 ⇧를 누르면 45° 단위로 고정된다.
- **M-11 글자**
  1. T → 클릭 → 바로 영어 입력. Esc 또는 바깥 클릭으로 끝낸다.
  2. 한국어 입력으로 바꿔 "한글 입력 확인"을 치고 **마지막 글자 조합 중(스페이스 없이)** 바로 바깥을 클릭한다. 기대: 마지막 음절까지 남는다.
  3. 입력을 끝낸 순간 글자가 위아래로 움직이는지 본다(보고서 BUG-06).
  4. 더블클릭으로 다시 편집되는지, 굵기 1·2·3에 따라 크기가 18/24/36(pt 기준)으로 바뀌는지 확인.
  5. 입력 중 ⌘Z는 글자만 되돌리고 문서 기록은 건드리지 않는지 확인.
- **M-12 도형**: R(도형) → 사각형·둥근 사각형·타원·선을 도형 묶음 메뉴에서 바꿔 가며 그린다. ⇧ 누른 채 정사각·정원·45° 선이 되는지 확인.
- **M-13 펜**: P로 빠르게 원을 그린다. 기대: 각지지 않고 부드럽다.
- **M-14 형광펜**: H로 같은 자리를 한 획 안에서 왕복한다. 기대: 겹친 곳이 더 진해지지 않는다. 두 번째 획이 겹치는 곳은 진해져도 된다. 기본색이 분홍일 때 노랑으로 그려지는지 확인.
- **M-15 모자이크**: B로 작은 글씨(11pt) 위를 덮고 끌기 탭으로 PNG를 내보낸 뒤 확대해서 글자를 읽을 수 없는지 본다.
- **M-16 스탬프**: S → 묶음 메뉴에서 ✓·✕·?·!·★·숫자를 각각 놓는다. 숫자는 1, 2, 3 자동 증가. 선택 후 오른쪽 아래 손잡이로 크기 조절.
- **M-17 자르기**: C → 영역을 끈다 → Enter. 기대: 캔버스가 줄고 ⌘Z로 원래대로. 손잡이로 범위 조절, Esc 취소도 확인.
- **M-18 캔버스 넓히기**: 이미지 네 변 바깥 띠에 마우스 → 분홍 "＋" → 클릭. 기대: 그쪽에 흰 여백(짧은 변의 25%, 최소 40px). ⌘Z로 되돌림.
- **M-19 선택·편집**: V → 주석 클릭·끌기·손잡이·Delete. 여러 개 ⇧클릭, ⌘A. 선택한 주석의 색·굵기를 바꾼다. **편집 창 두 개를 열고, B 창에서 주석을 그린(선택된) 상태로 A 창에서 색을 바꾼 뒤 B 창 주석 색이 바뀌는지 본다**(BUG-04).
- **M-20 색과 굵기**: 작은 영역(가로 300pt 이하, 세로 300pt 이하)을 캡처해 편집 창 왼쪽 막대에 색 원과 굵기 점이 보이는지 확인(BUG-01). 색 8개 + 사용자 지정, 굵기 3단을 바꾸고 앱을 종료·재실행해 마지막 도구·색·굵기가 남는지 확인.
- **M-21 실행 취소**: 그리기, 옮기기, 크기 조절, 글자, 스탬프, 자르기, 넓히기, 지우기, 화살표 키 이동, 색·굵기 바꾸기를 차례로 한 뒤 ⌘Z로 하나씩, ⇧⌘Z로 다시. 사용자 지정 색 패널에서 색을 끌어 바꾼 뒤 ⌘Z가 몇 번 필요한지 본다(BUG-07).
- **M-22 단축키**: ABC 입력 소스에서 A·T·R·O·L·P·H·B·S·C·V를 차례로 누르고 도구가 바뀌는지 본다(O·L은 BUG-03). **한국어 입력 소스로 바꿔 같은 키를 누른다**(BUG-08). 글자 입력 중에는 도구가 바뀌지 않아야 한다.

### 내보내기·보관

- **M-30 끌기 탭**: 아래 분홍 탭을 끌어 Slack, 카카오톡, 메일, Finder, Notion(앱·웹), 미리보기, Pages에 놓는다. 기대: 주석이 합쳐진 PNG가 들어간다. 글자 입력 중에 바로 탭을 끌어도 글자가 포함되는지 확인.
- **M-31 복사**: 아무것도 선택하지 않고 ⌘C → 다른 앱에 붙여 넣기. 툴바 "복사" 버튼도 확인.
- **M-32 저장**: ⌘S → PNG로 저장, 형식을 JPEG로 바꿔 확장자가 .jpg로 바뀌고 저장되는지 확인. 작은 캡처에서 툴바 오른쪽 "복사·저장" 버튼이 보이는지 확인(BUG-02).
- **M-33 자동 보관**: 캡처 후 주석을 그리고 1초 기다린다. `~/Pictures/Kkok/<날짜 시각>.png`가 갱신되고 `~/Library/Application Support/Kkok/history/<UUID>/`에 original.png·doc.json·thumb.png가 있는지 확인. 같은 초에 두 번(⇧⌘6 연타) 찍어 이름 끝에 " 2"가 붙는지 확인. **주석을 그리자마자(0.6초 안에) 또는 글자 입력 중에 ⌘Q로 종료**한 뒤 다시 열어 마지막 편집이 남는지 확인(BUG-05).
- **M-34 다시 편집**: 메뉴 막대 → 최근 항목에서 지난 캡처를 연다. 기대: 주석이 개별로 선택·이동·삭제된다.

### 앱

- **M-40 메뉴 막대**: 아이콘 메뉴에 영역/직전 영역/창/전체/타이머, 클립보드에서 새로 만들기, 파일 열기, 최근 항목, 설정, 종료가 있고 각각 동작.
- **M-41 로그인 시 실행**: 처음 실행 뒤 시스템 설정 › 일반 › 로그인 항목에 Kkok이 켜져 있는지. 설정 창 체크를 끄고 켜며 반영되는지. 로그아웃·로그인으로 실제 실행 확인.
- **M-42 단축키 설정**
  1. 설정에서 영역 캡처 칸을 눌러 ⌃⌥K로 바꾼다 → 바로 동작, 이전 ⇧⌘5는 동작 안 함.
  2. 칸을 누른 채(“키를 누르세요…”) 다른 것을 누르지 말고 설정 창을 빨간 버튼으로 닫는다 → 다른 캡처 단축키(⇧⌘6 등)가 여전히 동작하는지(BUG-09).
  3. 시스템 설정 › 키보드 › 단축키 › 스크린샷에서 macOS ⇧⌘5를 켠 상태로 Kkok을 다시 실행 → Kkok이 "등록하지 못함"을 알리는지, 실제로 어느 쪽이 반응하는지(BUG-10).
  4. 두 캡처 방식에 같은 단축키를 지정해 보고 안내 문구를 확인.
- **M-43 권한 안내**: 시스템 설정에서 Kkok의 화면 기록 권한을 끈 뒤 캡처 → 이유 설명과 "시스템 설정 열기" 버튼이 나오고, 누르면 해당 화면이 열린다.
- **M-44 캡처 후 동작**: 설정 창에 "캡처 후 클립보드에도 복사" 항목이 있는지(BUG-11).
- **M-NF 비기능**: 모니터 2대 연결 상태에서 ⇧⌘5 → 십자선까지 걸리는 시간을 체감(0.3초 이내 목표). Wi-Fi를 끈 상태로 모든 기능이 되는지. 3000×2000 이미지(⌘O)에 주석 50개를 그린 뒤 끌기가 끊기지 않는지.
